# 경산자인학교 과정중심평가 관리

단원별 관찰 메모를 바탕으로 **교과학습발달상황** 문장을 만들고,
나이스 입력 화면에 **자동으로 채워 넣는** 도구입니다.

기록은 선생님 컴퓨터 안에만 저장되며, 학생 정보가 외부 서버에 보관되지 않습니다.

---

# 📥 선생님용 — 설치하기

## 1단계 · 파일 내려받기

1. 이 페이지 위쪽의 초록색 **`< > Code`** 버튼을 누릅니다.
2. 메뉴 맨 아래 **`Download ZIP`** 을 누릅니다.
3. 받은 `gsjain-assessment-app-main.zip` 을 **압축 해제**합니다.
   (파일 우클릭 → `압축 풀기` → `압축 풀기`)
4. 생긴 폴더를 **바탕화면**처럼 찾기 쉬운 곳에 둡니다.

> 폴더 이름은 바꾸셔도 되지만, **폴더 안의 파일 이름은 바꾸지 마세요.**

## 2단계 · 앱 실행하기

폴더 안의 **`실행.bat`** 을 더블클릭하면 브라우저가 열립니다. 끝입니다.

검은 창이 하나 같이 뜨는데 **끄지 마세요.** 그 창이 꺼지면 앱도 닫힙니다.
다 쓰신 뒤에는 검은 창을 닫으시면 됩니다.

> **`index.html` 을 직접 더블클릭하지 마세요.**
> 그렇게 열면 입력한 내용이 저장되지 않고 사라집니다. 반드시 `실행.bat` 으로 여세요.

> `실행.bat` 이 안 되면 파이썬이 없는 것입니다.
> [python.org](https://www.python.org/downloads/) 에서 설치하실 때
> **`Add Python to PATH`** 를 꼭 체크하세요.

첫 화면 비밀번호는 **`1011`** 입니다.

## 3단계 · 나이스 자동입력 확장 설치 (엣지)

문장을 나이스에 자동으로 넣으려면 확장을 한 번 설치해야 합니다.

1. 엣지 주소창에 **`edge://extensions`** 를 입력하고 엔터
2. **왼쪽 아래 「개발자 모드」** 를 켭니다
3. 위쪽에 나타난 **「압축을 풀린 확장 로드」** 를 누릅니다
4. 압축 푼 폴더 안의 **`neis-extension`** 폴더를 선택합니다
5. 주소창 오른쪽 **퍼즐 🧩** → 「교과학습발달상황 입력 도우미」 옆 **압정 📌** 을 눌러 고정합니다

크롬에서도 같은 방법으로 됩니다 (`chrome://extensions`).

**도구 모음의 아이콘을 누르면 화면 오른쪽에 패널이 펴지고, 다시 누르면 접힙니다.**
나이스 화면을 클릭해도 패널은 닫히지 않으므로, 입력이 진행되는 것을 보면서 작업할 수 있습니다.

# 📝 쓰는 순서

1. **반 · 학생 · 과목 · 단원**을 등록합니다 (처음 한 번만)
2. **단원별 메모**에서 학생마다 도달 수준(상·중·하)과 관찰 내용을 적습니다
3. **교과학습발달상황** 화면에서 과목을 고르고 **「전체 일괄」** 을 누릅니다
4. 만들어진 문장을 확인하고 필요하면 직접 고칩니다
5. **「📋 [나이스] 복사」** 를 누릅니다
6. 나이스 교과학습발달상황 입력 화면을 열고, **확장 아이콘**을 눌러 패널을 폅니다
7. 패널의 **「📋 붙여넣기」** 를 누릅니다 (확인까지 한 번에 됩니다)
8. **「자동 입력 시작」** 을 누릅니다
9. 화면에서 내용을 확인하고 **직접 저장**합니다

> **확장은 저장 버튼을 누르지 않습니다.**
> 학생부는 되돌리기 어려우므로, 저장은 반드시 선생님이 눈으로 확인하고 누르셔야 합니다.

## 알아두시면 좋은 것

- **이미 만든 학생은 다시 만들지 않습니다.** 「전체 일괄」을 다시 눌러도 빠진 학생만 채웁니다.
  다시 만들고 싶으면 학생별 **「재생성」** 을 쓰세요.
- 생성에 실패한 학생(`[오류]`)은 **[나이스] 복사에서 자동으로 빠집니다.**
- 분량은 **나이스와 같은 UTF-8 바이트 기준**으로 표시됩니다.
- 학기 초에 한 번 **「💾 데이터 백업」** 을 눌러 파일을 보관해 두세요.
  브라우저 기록을 지우거나 컴퓨터를 바꾸면 기록이 사라집니다.
  **「📂 데이터 복원」** 으로 되살릴 수 있습니다.

# 🛠 개발자용

## 파일 구조

| 경로 | 역할 |
|------|------|
| `index.html` | 화면 껍데기와 스타일 |
| `app.jsx` | **소스** — 앱 로직은 여기를 고칩니다 |
| `app.js` | **빌드 결과물** — 직접 고치지 마세요 |
| `preset.js` | 교육과정 평가기준 프리셋 |
| `vendor/` | React 18 UMD (오프라인 동작용, 배포에 포함) |
| `neis-extension/` | 나이스 자동입력 확장 |
| `build/` | 빌드 도구 (배포에는 불필요) |

## 빌드

`app.jsx` 를 고쳤으면 `app.js` 를 다시 만들어야 반영됩니다.
node/npm 없이 브라우저의 Babel 로 변환합니다.

```bash
python build/build.py
```

터미널에 나온 주소를 브라우저에서 열고, "완료" 가 보이면 창을 닫은 뒤 `Ctrl+C`.

`index.html` 이나 `preset.js` 만 고쳤다면 빌드 없이 새로고침하면 됩니다.

## AI 프록시

문장 생성은 [`juninn9910/anthropic-proxy`](https://github.com/juninn9910/anthropic-proxy) 를 거칩니다.
API 키는 그 프록시의 환경 변수에 있고, 이 저장소에는 들어 있지 않습니다.

`app.jsx` 의 `APP_TOKEN` 은 프록시의 `APP_TOKEN` 환경 변수와 **같은 값**이어야 합니다.
바꿀 때는 양쪽을 함께 바꾸고 프록시를 재배포하세요.

## 확장이 기대하는 JSON

```json
[
  {"name": "홍길동", "num": "1", "text": "…"},
  {"name": "김철수", "num": "2", "text": "…"}
]
```

`num` 은 동명이인을 구분할 때만 쓰입니다.

## 나이스 화면 관련 메모

나이스 입력 화면은 일반 HTML 폼이 아니라 그리드 위젯이 그립니다. 확장은 이 성질에 맞춰 동작합니다.

- 학생 행은 `.cl-grid-row[data-rowindex]` (헤더 행에는 `data-rowindex` 가 없음)
- 셀: `1`=반/번호, `2`=성명, `4`=바이트 카운터, `7`=입력칸
- **선택된 행에만 `<textarea>` 가 생깁니다**
- 값은 **다른 행으로 선택이 옮겨갈 때 확정**됩니다. `input` 이벤트만으로는 사라집니다
- 바이트 카운터는 **UTF-8 기준** (한글 3바이트)
- `change` / `keyup` 이벤트는 그리드 내부 오류를 유발하므로 보내지 않습니다
